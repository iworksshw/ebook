01护照有效期限及签证居留期限的确认

外国人访问大韩民国时需持有有效的护照和法务部长官发行的签证。如果是和大韩民国签订了 免签协议或可以无签证入境的情况，则无需签证也能够入境。先确认好护照和签证的有效期， 以防延长居留期限时发生意料之外的情况。

护照

记载持有者国籍等个人信息的身份证，必须携带。

读大韩民国入境签证
  • 居留资格 : 可以知道来韩国的目的(结婚移 民者 ：居留资格 F-6)
  • 入境审查确认证日期是入境日期 从第二天开始计算在韩国的居留期限
  • 居留期间根据居留资格等有所不同。需在到期前(自入境日期 90日以内)申请外国人登录证及延长居留期限。(根据居留资 格、申请人的延长事由等居留期限可延长与否不尽相同。
  • 滞留期限下方到期日为签证(Visa)有效期。

02外国人登录

(1)外国人登录对象及时期

在大韩民国居留90天以上的外国人必须在90天以内申请外国人登录。

  • 在大韩民国居留期间，新授予居留资格或居留资格变更时，应在被授予居留资格或居留资格 变更时同时申请外国人登录。

(2)所需资料

共同资料
  • 护照(+原件，复印件)
  • 综合申请书(出入境·外国人厅(事务所·办事处) 信访室备有附件34号格式)
  • 护照用规格照片 (规格 3.5cm x 4.5cm) 1张
    • 6个月内拍摄的白底彩色正面照
  • 登录证发放手续费30,000韩元（现金）
  • 居 留地证明资料
    （根据居留资格类型所需资料会有所差异，请务必向外国人综合服务中心

(3)结婚移民者形

除了上述资料以外，还需要提交韩国人配偶（韩国人丈夫或者妻子）的如下资料。

  • 婚姻关系证明(详细)
  • 居民登记副本
  • （如有子女）子女的家庭关系证明
    • 申请日为准3个月内发放
  • 居留地证明材料
    • 登录证发放手续费30000韩元+延期手续费30000韩元
      • 结核检查义务化对象国在申请签证时，提交结核检查确认单（2020年4月）
      • 限结婚移民者早期适应培训项目进修者可居留2年。

(4)外国人登录申请及签发

外国人登录申请及（补）签发可以在居留地管辖出入境·外国人厅（事务所·办事处）进行。

外国人登录证领取方法

外国人登录证领证日期自申请之日需3周以上时间，可直接访问事务所领取。若不想访问事 务所，希望在家领证，可在申请外国人登录证时事先支付快递费用并申请快递则可在居留地 址收取。

(5)外国人登录证的管理

外国人登录证是证明其为外国人的身份证，因此必须随身携带。若违反携带义务则可处于 1,000,000韩元以下行政罚款处分。

外国人登录证的补发 :

若发生下列事由，应向所在辖区的出入境·外国人厅（事务所·办事处）申请补发。

  • 丢失外国人登录证
  • 外国人登录证破旧不能使用
  • 所需事项记载栏不够
  • 姓名、性别、出生日期、国籍有变化
所需资料
  • 护照
  • 综合申请书
  • 彩照(3.5cm x 4.5cm) 1张
  • 登录证发放手续费30,000韩元
  • 外国人登录证返还 ：发生如下情况时，需返还外国人登录证。

03居留期限延长

(1)对象及时期

超过许可的居留期限，继续居留在大韩民国的外国人，到期前4个月开始到到期日申请延长居留 期限。到期日后申请延长时有额外的罚款。

(2)居留期限延长程序

    受理
    (出入境公务员)
    审查
    必要时核实
    许可与否
    (审批)
    许可事项电算输入及记载
    领取护照等
    (外国人)

(3)所需资料

  • •综合申请书
  • 护照及外国人登录证（已进行外国人登记时）
  • 居留地址证明材料
  • 各居留资格追加资料
  • 手续费60,000韩元（结婚移民(F-6)为30,000韩元)
结婚移民者需追加提交的资料
  • 韩国人配偶者的婚姻关系证明（详细）
  • 韩国人配偶者的户口簿副本
  • (如有子女）子女的家庭关系证明
  • 居留地证明材料(仅当韩国人配偶的地址和结婚移民者的居留地不一致时需要) 但出入境•外国人厅(事务所)所长在受理和审查过程中认为特别必需的情况下，可能增减部分材料。
  • 根据滞留资格要求提交的材料各不相同，请务必向外国人综合服务中心☎1345确认)。

04居留资格的变更

(1)对象及时期

在大韩民国居留的外国人想终止同现在居留资格相对应的活动从事同其它居留资格相对应的 活动时，在从事同其它居留资格相对应的活动之前，应得到辖区出入境·外国人厅(事务所·办事 处)许可。

  • 临时访问中的团体观光等(C-3-2)在国内的资格变更受限制。
  • 完成语言进修（D-4），上大学留学时（D-2）
  • 在韩国的其他居留资格（90天以内的短期签证持有者，非法居留者除外）的外国人，与韩国人 结婚后想更改为结婚移民（F-6）时

(2)所需资料

  • 综合申请书、标准规格的照片1张
  • 护照及外国人登录证（已进行外国人登记时）
  • 所申请居留资格对应的附加资料
  • 变更资格手续费100,000韩元(发放登录证手续费30,000韩元另计)
    • 永驻(F-5)资格变更为200,000韩元(永驻证发放手续费30,000韩元另计)

05居留资格以外的活动

(1)对象及时期

91天以上长期居留（90天内的短期签证持有者除外）的外国人在当前的居留资格下同时从事同 其它居留资格相关的活动时，在从事其它居留资格相对应的活动之前必须取得居留资格以外的 活动许可。

  • 持有留学(D-2)及语言研修(D-4-1,D-4-7)资格并获得留学生负责人确认的人(有专门具体资 格条件，请咨询☎1345)
    • 语言研修生自入境日过6个月后审批
  • 以宗教居留资格（D-6）活动的传教士在同一财团的下属机构讲课（E-1）时

结婚移民者（F-6）在就业方面并无限制，不需要其他的居留资格外的活动许可。但即便是许可 的就业活动，如果根据韩国法令需要具备一定的资格或条件时，应该具备相应资格（条件）。

(2)所需资料

  • 综合申请书
  • 护照及外国人登录证（已进行外国人登记时）
  • 所申请居留资格对应的附加资料
  • 手续费120,000韩元，但持留学（D-2）、一般进修（D-4）签证者无手续费

06再入境许可

(1)对象

  • 在韩国居留91天以上，申请外国人登录者
  • 在韩国的外国公馆和国际机关的人员及其家属，根据韩国政府的协定，外交官和领事或享受 类似的特权和地位的人及其家属等免外国人登录的人

(2)期间

  • 仅允许单次入境的单数再入境最长期间 : 1年
  • 允许2次以上入境的多数再入境最长期间 ：2年

(3)免再入境许可及其对象

  • A-1~A-3或已登录的外国人（所有居留资格）在出国日起1年以内，再入境的情况下，不需要再 入境国家许可（居留期限少于1年时，在居留期限内免除）
  • F-5（永住）资格持有者出国日起2年内再入境时

(4)所需资料

  • 综合申请书
  • 签证和外国人登录证（已登录的外国人）
  • 手续费-单数:30,000韩元，多数:50,000韩元

(5)再入境许可期限的延长

收到再入境许可后出境的外国人在许可期限或豁免期限内发生不可入境的事由时，应在许可期 限内到当地大韩民国大使馆或领事馆办理延长申请。如果无法在再入境许可期间内入境，将会 失去原来持有的居留资格。

07外国人的申报义务Point!

已办理外国人登录的外国人若发生如下事由，有义务自发生事由之日起15日内 向居留地或管辖出入境外国人厅(事务所·办事处)所申报，违者将予以行政罚款 或违章罚款，且可能会遭到居留相关损失，敬请注意。

(1)申报事由

已登记的外国人发生下列事由时，须从事由发生之日起15天以内到居留地或工 作地区所在辖区的出入境外国人厅(事务所·办事处)办理外国人登记事项变更申 报。

  • 姓名、性别、出生年月日及国籍变更时
  • 护照号码、发放日期、有效期限发生变更时
  • 持有D-1, D-2, D-4~D-9资格持有者的所属机构或团体变更（包括名称变更）或增加
  • D-10资格持有者开始研修的事实或研修机构的变更（包括名称变更）
  • H-2资格持有者首次被个人、机构、团体或公司雇用时，其就业开始事实
  • H-2资格持有者已经被个人、机构、团体或公司雇用时，该个人、机构、团体或公司的变更及名称变更
  • 居住地变更

(2)所需材料

  • 申报单
  • 护照及外国人登录证
  • 变更事项证明资料(居留地变更时，可证明地址的文件)

何谓检疫？(动·植物检疫)

为防止海外家禽传染病及植物病害虫等流入韩国国内，全国机场、港湾实施入境前检疫。 若持禁止携带农·畜产品入境却不申报将可受到行政罚款、入境限制等处罚。

  • “携带农·畜产品入境时必须在旅行者携带品申报单打钩并向位于机场· 港湾的农林畜产检疫本部申报。”
检疫流程
  • 到达韩国(机场、港湾、邮局)
  • 入境审查
  • 填写海关申报表(申报检疫)
  • 动物、植物、农产品、畜产品检疫 : 检疫结果合格时才予以通过。
  • 海关检查
  • 入境
动物·畜产品检疫
  • 禁止携带运入的畜产品
    1. 1肉及肉制品：牛肉、猪肉、鸡肉、鸭肉、香肠、火腿、肉干、熟肉等
    2. 2加工乳制品 : 牛奶、奶酪、黄油等
    3. 3卵及卵加工品 : 鸡蛋、鸟类卵、蛋白、蛋粉等
    4. 4宠物饲料、零食类及营养剂等
